# مسار RTC — مركز رسالة التدريبي (الإصدار 9.0)

تطبيق عربي (PWA) لإدارة مستفيدي كورسات جمعية رسالة: تسجيل Google، حضور، نقاط، شهادات قابلة للتحقق، وإشراف للمتطوعين.

كل حساب جديد يدخل **طالباً**. المشرف الوحيد يُثبَّت من السيرفر. المشرف يرقّي أي شخص إلى متطوع.

## التشغيل

```bash
npm install
npm run dev
# http://localhost:5173
```

## قبل أول استخدام حقيقي

طبّق السكيمة على مشروع Supabase كما في [`APPLY-SCHEMA.md`](APPLY-SCHEMA.md).

## الأمان (ما تغيّر في v9)

- الهوية من جلسة JWT فقط. لا دخول عبر `localStorage`.
- الدور والنقاط لا يُكتبان من العميل (صلاحيات أعمدة + trigger).
- عمليات الحضور والانضمام والشهادات وتغيير الدور عبر دوال `SECURITY DEFINER`.
- Route guards على كل شاشة.
- الهاتف مقنّع للمتطوع. التحليلات الكاملة للمشرف.
- صفحة تحقق عامة `verify.html` بلا PII زائد.

## الأدوار

| الدور | كيف يُمنح |
|---|---|
| طالب | افتراضي لكل تسجيل Google |
| متطوع | المشرف فقط من شاشة المستخدمين |
| مشرف | حساب مؤسِّس السيرفر فقط |
