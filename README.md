# مسار RTC — مركز رسالة التدريبي (الإصدار 8.0)

> تطبيق موبايل عربي متميز (PWA + Native-ready عبر Capacitor) لإدارة ومتابعة المستفيدين في جمعية رسالة — من التوثيق والتسجيل عبر Google، وتتبع الحضور والنقاط، وصولاً إلى الشهادات المعتمدة وقاعدة البيانات الحقيقية.

---

## ✨ المميزات الرئيسية

- **تسجيل دخول احترافي عبر Google OAuth** — توثيق آمن ومباشر عبر خوادم Supabase.
- **مسار تسجيل مُبسط (2-Step Onboarding)** — الربط بحساب Google، ثم استكمال رقم الهاتف والفرع فقط.
- **تكامل حقيقي مع قاعدة البيانات (No Dummy Data)** — الربط الكامل المباشر بـ Supabase، واستعلامات حقيقية بدون بيانات وهمية.
- **تصميم عصري (Apple-Tier UX/UI)** — بطاقات تفاعلية، شاشات سفلیة (Bottom Sheets) مخصصة بدلاً من القوائم التقليدية، وتأثيرات Glassmorphism ناعمة.
- **3 أدوار بواجهات منفصلة** — طالب 🎓 / متطوع 🤝 / مشرف ⚙️ مع حماية المسارات (Route Guards).
- **شهادات معتمدة ورقمية** — تنزيل مباشر بصيغة PDF وتوثيق معتمد بزر تحقق من الشهادة.
- **وضع ليلي متطور (Dark OLED)** — مع إمكانية التبديل الفيزيائي السلس.

---

## 🛠️ التقنيات المستخدمة

| الطبقة | التقنية |
|--------|---------|
| **الواجهة** | Vanilla JS + TailwindCSS + Design System V8.0 (Academic Core) |
| **قاعدة البيانات والتوثيق** | Supabase (Live Database + Auth + OAuth + RLS Policies) |
| **الأيقونات والخطوط** | Phosphor Icons + IBM Plex Sans Arabic |
| **PWA & Offline** | Service Worker + Web Manifest |
| **الموبايل** | Capacitor 8 (Android + iOS) |

## 📄 البيانات والأمان (Supabase Schema)

توجد شفرة جداول وسياسات الأمان في الملف:
`supabase_schema.sql`

تشمل الجداول الأساسية:
- `profiles` (بيانات المستخدمين والأدوار والفروع)
- `courses` (الكورسات التدريبية)
- `batches` (المجموعات والمواعيد)
- `enrollments` (تسجيل الطلاب في المجموعات)
- `attendance` (سجل الحضور والغياب)
- `certs` (الشهادات المعتمدة)
